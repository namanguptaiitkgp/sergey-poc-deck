POC design

Hypothesis, metrics, duration, sample

Hypothesis

If we reply to freight enquiries with a credible indicative rate within a defined SLA using a lean process, onboarded agents will engage more (and we learn corridor / SLA requirements for the product).

Success metrics (draft)
  • • % enquiries with indicative reply within SLA
  • • Median time-to-rate
  • • Agent response / continuation rate
  • • Qualitative: “useful enough to quote forward”
Duration & sample
  • • 2 weeks active experiment window
  • • 8–15 freshly onboarded agents (discuss)
  • • Focus corridors: pick 1–2 where outreach already warm
  • • Cap daily volume so SLA is honest
